# AI Faculty

An ever-expanding, industry-specific **AI education institution** structured like a university
faculty — specialised AI teaching roles under human oversight, designed to scale from one learner
to hundreds of thousands without diluting quality.

Design-stage. Building mobile-first / documentation-led. See [docs/PROJECT-BRIEF.md](docs/PROJECT-BRIEF.md)
for the full absorbed architecture.

> Separate project — not related to MindMend.
