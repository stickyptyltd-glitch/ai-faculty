# AI Faculty — Competency Framework

**Version:** v0.1
**Principle:** the institution is **capability-first, not course-first**. A course is something we
deliver; a competency is something the learner can *actually do*.

---

## Master capability #1

### AI-Assisted Workflow Designer

> A learner who can reliably design, test, verify and improve AI-assisted workflows for real
> personal or professional tasks.

Context tracks: **Personal · Professional · Mixed** (assigned by diagnostic; switching tracks never
deletes prior evidence).

## Decomposition — seven competencies

| ID | Competency | The learner can… |
|---|---|---|
| **C1** | Goal Definition | Define the real outcome a workflow needs to achieve |
| **C2** | Workflow Structuring | Break the outcome into logical steps |
| **C3** | AI Role Design | Decide where and how AI should be used |
| **C4** | Verification Design | Identify what must be checked and how |
| **C5** | Workflow Testing | Test the workflow against realistic cases |
| **C6** | Workflow Improvement | Use evidence to improve performance |
| **C7** | Responsible Application | Recognise limitations, risks and appropriate human oversight |

These are seven capabilities, not seven lessons — each may need a different mix of learning
experiences.

## Competency levels

| Level | Name | Meaning |
|---|---|---|
| 0 | Unfamiliar | Cannot yet perform it reliably |
| 1 | Understand | Can explain the concept and recognise examples |
| 2 | Guided | Can perform it with substantial support |
| 3 | Independent | Can perform it independently in a familiar context |
| 4 | Transfer | Can adapt it to substantially different contexts |
| 5 | Design | Can create improved approaches and explain the reasoning |

## Mastery rubric dimensions

Clarity · Structure · Verification · Reasoning · Evidence · Transfer · Safety.

- **Personal track mastery:** clear workflow, logical steps, deliberate AI use, verification present,
  evidence of improvement.
- **Professional track mastery:** context fit, risk awareness, rigorous verification, explicit
  reasoning, strong evidence.

## First learning pathway (10 stages)

Diagnose → Mental models → Working with AI → Verification → Workflow design → Iteration →
Application → Demonstration → Reflection → Advance.
Each stage carries both a personal and a professional example.

## The AI Capability Graph

C1–C7 form the first node of a graph that expands, without forcing every learner down one linear line:

```
AI literacy → workflow design → automation → agents → data → evaluation
→ AI product design → AI science → industry-specific AI → advanced research
```
